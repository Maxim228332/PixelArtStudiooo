# Pixel Art Studio — Android

Нативное Android-приложение на Java, интерфейс на русском языке.

## Что внутри

- Рисование пальцем по пиксельной сетке: карандаш, ластик, заливка, пипетка.
- Размер холста от 16×16 до 256×256.
- Палитра, выбор RGB, смешивание цветов, генерация оттенков.
- Импорт картинки-референса, регулировка её прозрачности и включение/выключение сетки.
- Отмена/повтор действий.
- Экспорт PNG с прозрачным фоном или вместе с референсом.
- ИИ-генератор по текстовому описанию: изображение автоматически превращается в пиксель-арт.
- Режим «Раскраска по номерам» с 8, 12 или 16 цветами, номерами на клетках и проверкой правильного цвета.

## ИИ: важные детали

Генерация изображений использует OpenAI API. Нужен отдельный API-ключ от платформы OpenAI и доступный API-баланс. Подписка ChatGPT сама по себе не оплачивает вызовы API; каждый запрос может стоить денег. Приложение не содержит заранее вшитого ключа. Введённый ключ хранится в приватных настройках приложения на этом устройстве, но не является серверным секретным хранилищем. Не публикуйте APK с сохранённым ключом и не используйте чужие ключи.

Сетевой запрос выполняется по HTTPS. При ошибке API приложение показывает её причину (например, неправильный ключ или отсутствие доступного баланса).

## Как получить APK через GitHub Actions

В рабочей среде, где создавался проект, нет установленного Android SDK/Gradle и заблокирована загрузка зависимостей, поэтому готовый скомпилированный APK не включён в архив. В репозитории уже настроен workflow, который собирает APK на GitHub.

1. Распакуйте архив на компьютере.
2. Создайте пустой репозиторий на GitHub.
3. Загрузите в репозиторий содержимое папки `PixelArtStudioAndroid` (с сохранением структуры, включая папку `.github`).
4. Откройте вкладку **Actions** и дождитесь завершения задачи **Build Android APK**.
5. Откройте успешный запуск workflow и скачайте artifact **PixelArtStudio-APK**. В архиве artifact будет файл `app-debug.apk`.
6. Отправьте APK себе на телефон, откройте его и разрешите установку приложения из этого источника, если Android спросит.

## Локальная сборка

Нужны Android SDK (platform 35) и JDK 17. Затем из корня проекта:

```bash
gradle --no-daemon assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
